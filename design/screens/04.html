  • 发送键变停止；模型胶囊就是“Change model”，任务中可换。
  • 运行中也能在输入框里补充一句：默认排队，显示在输入框上方，这一轮做完后作为下一轮发给 Agent，多条按顺序各跑一轮。“立即发送”把它插进当前这一轮：它立刻离开队列，成为转录里的用户气泡，下面注“Agent 下一步读到”，直到 Agent 在下一步收到它（工具调用跑得久时可能要等几分钟）；× 移除。排队的那条在 Agent 收下后离开队列，变成转录里的用户气泡，位置就是 Agent 收到它的地方。打字时发送键代替停止，发出后停止键回来。
  • 停止任务时，还在排队的话放回输入框，不会偷偷发出。断线重连后队列和顺序不变。任务完成后接着说见 06，停止后接着说见 X1。
